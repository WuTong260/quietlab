# QuietLab · 安静的小工具箱

QuietLab 是一个使用 Python 标准库编写的离线工具箱：八个实用工具、一个终端交互菜单，以及可打印、可游玩的迷宫。Python 3.9+，零第三方依赖。当前版本 **1.1.0**。

**程序只从你明确提供的参数或标准输入读取内容，把结果打印到标准输出。没有文件写入、网络、模型请求、后台服务或自动保存功能。**

下载仓库 ZIP 并解压，或克隆仓库：

```sh
git clone https://github.com/WuTong260/quietlab.git
cd quietlab
python3 -B menu.py
```

也可直接运行命令行工具：

```sh
python3 -B quietlab.py --help
python3 -B quietlab.py calc '0.1 + 0.2'
```

`-B` 告诉 Python 不生成字节码缓存。下面的命令都只打印结果；没有保存、覆盖或删除操作。

## 先从交互菜单开始

macOS 可以双击本目录的 `打开 QuietLab.command`，在终端里打开菜单。它使用系统的 `/usr/bin/python3`，不会安装环境或修改配置。如果系统不允许双击脚本，可直接在终端运行：

```sh
python3 -B menu.py
```

输入菜单数字即可使用。任务规划会逐项询问名称、时间和价值，不再要求手写 JSON；文本比较会分别接收原文和新文。粘贴多行内容后，用单独一行 `.` 结束输入；若文本本来有一行只有一个点，则输入 `..`。每个输入行会包含一个末尾换行；需要比较“末尾无换行”的精确差异时，请使用原来的 JSON 命令行接口。

输入 `:cancel` 放弃当前操作，`q` 退出菜单；Ctrl+C 或输入结束也会退出。超过输入大小限制时会直接结束会话，防止把剩余大段输入误当作菜单命令。输入内容不由程序保存，终端自身仍可能保留屏幕回滚内容。

## 1. 计算器：十进制数与受限表达式

```sh
python3 -B quietlab.py calc '(1200 * 0.85 + 45) / 3'
python3 -B quietlab.py calc 'sqrt(81) + max(2, 3)'
python3 -B quietlab.py calc -- '-2**2'
```

支持 `+ - * / **`、括号和 `abs/min/max/sqrt`。保留 40 位有效数字；`0.1+0.2` 输出 `0.3`。不支持变量、属性访问、导入、文件、列表或任意 Python 执行。

幂指数限 -100 至 100 的整数，输入限 1024 字符，表达式的节点数和深度也有限制。精度限制意味着复杂计算仍然会舍入，不适用于精度未经验证的财务结算。

## 2. 文本概览

```sh
printf '你好 hello\n你好 hello\n' | python3 -B quietlab.py text
```

返回 UTF-8 字节数、Unicode 码点数、非空白码点数、行数、汉字码点数、拉丁字母单词数、重复非空行和异常控制字符。

“码点”并不等于用户看到的一个字：`e` 加组合重音计 2 个，`👩‍💻` 计 3 个。汉字数使用代码中标明的 Unicode 区段近似统计；不做分词。字符熵是字符频率的香农熵，**不能据此判断密码安全或压缩率**。空输入为 0 行；末尾换行不额外计为空行。

## 3. 严格 JSON 校验与整理

```sh
printf '{"b":2,"a":0.1234567890123456789}' | python3 -B quietlab.py json --sort-keys
```

拒绝重复键、NaN、Infinity 和不完整语法。小数使用 Decimal 读取，整理时保留其十进制数值，不通过二进制浮点数中转。数值表示方式可能改变，例如指数的大小写。数组顺序不变；只有指定 `--sort-keys` 才排序对象的键。

整数最多 1000 位；非零小数的十进制数量级在 ±1000 以内；最多 32 层、50000 个值节点。输出会把终端控制字符和不可打印格式字符转义显示。

## 4. CSV 概览

```sh
printf 'name,score\nAlice,10\nBob,2.5\nCarol,\n' | python3 -B quietlab.py csv
printf 'name\tscore\nAlice\t10\n' | python3 -B quietlab.py csv --delimiter tab
```

首行是表头，支持标准引号和引号内换行。分隔符需明确指定，默认逗号，也支持 `tab`、`;`、`|`。每列返回空值数、非空值数、有效数字数、最小值和最大值；数字用字符串输出以保留精度。

字段数不匹配的行单独计数并从各列统计中排除，最多列出前 20 个问题行。空白物理行由 CSV 解析器跳过；带引号的空字段是数据。重复表头会报告，不会合并列。最多 100 列、20000 行；标准库对单个字段还有约 128 KiB 的限制。数值识别限 1000 字符及 ±1000 数量级，其他内容仍计为非空文本。

## 5. 时间预算下选择任务

```sh
printf '[{"name":"读书","minutes":40,"value":7},{"name":"散步","minutes":30,"value":6},{"name":"整理笔记","minutes":20,"value":4}]' | python3 -B quietlab.py plan --minutes 60
```

在示例中会选择“读书 + 整理笔记”，用 60 分钟得到总价值 11。价值由你自己填写，程序不替你判断事情的重要程度。

这是精确的 0/1 背包计算，假设任务互相独立、不可拆分、每项最多选择一次。不处理依赖关系、固定开始时间或任务切换成本。价值相同时优先少用时间，再优先输入顺序靠前的组合；零价值任务不会占用时间。最多 100 个任务、1440 分钟。

## 6. 比较两段文本

```sh
printf '{"before":"hello\nworld\n","after":"hello\nquiet lab\n"}' | python3 -B quietlab.py diff
```

输出 unified diff 形式的预览，包括末尾缺少换行的提示。每侧最多 2000 行和 100000 字符。`--context 0` 到 `--context 10` 控制上下文行数。

控制字符会转义显示，所以这是便于阅读的比较预览，不保证可直接当作补丁应用到文件。

## 7. 手动分配额度

```sh
python3 -B quietlab.py budget --remaining 81 --reserve 35 --minutes 180
```

这是一个假设剩余 81%、预留 35%、持续 180 分钟的例子，生成最多消耗 46 个百分点的检查点。它只生成一个**累计消耗上限**，不要求把额度用完。

这不是账户余额查询或强制限额器：不会联网，不知道真实模型消耗，也不会控制任何客户端。实际工作时仍需读取真实账户额度。若读取失败，不能把估算当成已验证余额。示例数字是手动规划参数，不代表任何账户的实时余额。

## 8. 迷宫散步

已经生成了一份 [迷宫](maze-20261102.svg) 和对应的 [答案](maze-20261102-solution.svg)。从左上开口进入，右下开口出去。所有格子相通，两点之间只有一条简单路径。

```sh
python3 -B maze.py --width 25 --height 17 --seed 20261102
python3 -B maze.py --width 25 --height 17 --seed 20261102 --solution
```

命令向标准输出打印 SVG 源码。相同参数得到相同图案。宽度限 2–41、高度限 2–31，不会生成无限增长的地图。迷宫图是普通静态 SVG，不含脚本、字体下载、链接或外部图像。

交互菜单的第 8 项可以直接玩迷宫：`w/a/s/d` 移动，`h` 给出下一步提示，`r` 从入口重来，`q` 返回菜单。`@` 代表你，`E` 是出口，`.` 是已经走过的格子。抵达出口后显示实际步数和最短步数。交互版尺寸限 25×17，默认 15×9；它等待键盘输入，不会在后台循环刷新。

## 9. 单位换算

```sh
python3 -B units.py --list
python3 -B units.py 36 km/h m/s
python3 -B units.py 1 MiB MB
python3 -B units.py -- -40 C F
```

也可以使用交互菜单第 9 项。覆盖长度、质量、时间、速度、数据量与绝对温度，支持部分中文名称，如“公里”“米”“摄氏度”。前三个换算示例依次输出 `10`、`1.048576`、`-40`（不含列出单位的命令）。

换算系数用精确有理数表示，最后一步输出 40 位有效数字。普通十进制数值在检查绝对零度时保留输入精度；数值也可写成 `1/2` 等表达式，表达式使用计算器的 40 位工作精度。拒绝跨维度换算，以及低于 0 K 的绝对温度。

`KB/MB/GB` 使用十进制，`KiB/MiB/GiB` 使用二进制；`B` 是字节，`bit` 是比特，大小写有意义。`C/F/K` 表示绝对温度，不用于温差换算。这里不包含汇率、实时行情或财务估值。

## 资源与数据边界

- 通用输入最多 1 MiB，输出最多 2 MiB。JSON 格式化边生成边检查输出长度，防止深层缩进放大内存。
- 仓库中的例子和测试数据均为合成数据。
- 工具模块没有文件访问、进程启动、网络或任意代码执行入口。测试代码会启动短时 Python 子进程验证命令行行为。
- 不注册开机启动，不修改设置，不创建定时任务，不监听端口；命令运行完即退出。
- 不提供“所有风险为零”的保证。边界检查和测试降低了这次实现的可见风险；输出由你自己决定如何使用。
- 若自行添加 shell 输出重定向，文件操作来自 shell；请不要使用已有文件路径，以免覆盖。本说明中的命令均不含输出重定向。
